How Updating Works on GitHub Pages

GitHub Pages is a static website host with no database or server backend. Visitors cannot change your files. To add new projects or files, you make changes locally on your computer and push to GitHub using either method below:

Method 1: PowerShell Sync (Fastest)

Drop files/folders in your repo, then run:

powershell -ExecutionPolicy Bypass -File .\update-projects.ps1
Method 2: Visual Studio (Below)

Fill in the form below, drop files to add context, and click:

"Download Updated projects.js"

Ready to Publish to GitHub Pages?

After replacing projects.js or dropping your new media files into the repository folder, commit and push:

git add . git commit -m "Update portfolio projects and media" git push origin main

GitHub Pages will build and deploy the update globally in ~30–60 seconds.
